# پلتفرم حسابداری دستمزد پروژه‌های نصب

یک نرم‌افزار حسابداری **محلی (Local)** و **فارسی/راست‌چین** برای مدیریت دستمزد
پروژه‌های نصب. هر پروژه یک مبلغ دستمزد کل دارد و هر نیروی نصب درصد مشخصی از آن را
می‌گیرد؛ باقی‌مانده، سهم مغازه است.

> نسخه اول کاملاً **آفلاین** اجرا می‌شود، دیتابیس **SQLite** دارد و نیازی به
> سرور، هاست یا اینترنت ندارد.

## امکانات

- **داشبورد:** تعداد پروژه‌ها، مجموع دستمزد، سهم نیروها، سهم مغازه، هزینه‌های جانبی، **مانده واقعی مغازه**، بدهی هر نیرو، طلب از مشتری‌ها، پروژه‌های تسویه‌نشده.
- **مدیریت نیروها:** نام، تماس، درصد پیش‌فرض، وضعیت فعال/غیرفعال، توضیحات، یادداشت داخلی، ویرایش/حذف.
- **جستجو و فیلتر سریع:** جستجوی پروژه بر اساس نام پروژه، مشتری، **نام نیرو**، تاریخ و وضعیت؛ فیلتر تسویه‌شده/نشده و فیلتر پروژه‌هایی که مشتری هنوز کامل پرداخت نکرده.
- **ثبت پروژه:** انتخاب نیروها و درصد هر نیرو برای همان پروژه، با **محاسبه زنده** سهم‌ها و سهم مغازه.
- **اعتبارسنجی:** اگر مجموع درصدها بیش از ۱۰۰٪ شود، اجازه ثبت داده نمی‌شود.
- **مدیریت پرداخت‌ها:** ثبت، **ویرایش** و حذف پرداخت با تاریخ، مبلغ، توضیح و **روش پرداخت**؛ **جلوگیری از پرداخت بیشتر از مانده طلب** مگر با تأیید هشدار.
- **هزینه‌های جانبی پروژه:** بنزین، غذا، ابزار مصرفی، خرید جنس، ایاب‌وذهاب، سایر.
- **وضعیت دریافت پول از مشتری:** مبلغ کل قابل دریافت، دریافت‌شده، مانده طلب، وضعیت (دریافت نشده/ناقص/کامل) و **ثبت چند مرحله دریافت**.
- **خلاصه مالی هر پروژه:** دستمزد، سهم نیروها، هزینه‌ها، سهم مغازه قبل از هزینه‌ها و **مانده واقعی مغازه بعد از هزینه‌ها**.
- **چاپ / PDF پروژه:** خروجی کامل پروژه با امکان **مخفی‌کردن یادداشت‌های داخلی** در چاپ عمومی.
- **تسویه حساب نیروها:** صورتحساب کامل، ثبت/ویرایش پرداخت و تسویه کامل.
- **گزارش‌ها:** پروژه‌ها، درآمد مغازه، **سود واقعی مغازه (بعد از هزینه‌ها)**، سهم نیروها، بدهی، **عملکرد نیروها در بازه**، **طلب از مشتری‌ها**، تسویه‌نشده‌ها — با خروجی **Excel** و **PDF/چاپ**.
- **تنظیمات:** واحد پول، درصد پیش‌فرض مغازه، **بکاپ خودکار و دستی**، مدیریت کاربران، **خروج خودکار پس از بیکاری**.
- **ورود با نام کاربری و رمز عبور** (رمزها به‌صورت hash ذخیره می‌شوند) با **قفل خودکار پس از بیکاری**.

## فرمول محاسبه سهم

```
سهم هر نیرو      = مبلغ کل دستمزد × درصد نیرو ÷ ۱۰۰
مجموع سهم نیروها = جمع سهم همه نیروها
سهم مغازه        = مبلغ کل دستمزد − مجموع سهم نیروها
```

**مثال:** پروژه ۱۰٬۰۰۰٬۰۰۰ تومان با دو نیرو که هرکدام ۳۰٪ دارند:

| مورد | درصد | مبلغ (تومان) |
|---|---|---|
| نیروی اول | ۳۰٪ | ۳٬۰۰۰٬۰۰۰ |
| نیروی دوم | ۳۰٪ | ۳٬۰۰۰٬۰۰۰ |
| **سهم مغازه** | ۴۰٪ | **۴٬۰۰۰٬۰۰۰** |

> اگر مجموع درصد نیروها از ۱۰۰٪ بیشتر شود، سیستم خطا می‌دهد و ثبت نمی‌کند.
> اگر کمتر از ۱۰۰٪ باشد، باقی‌مانده به‌صورت خودکار سهم مغازه می‌شود.

## اجرا روی ویندوز

ساده‌ترین روش:

۱. [Python نسخه ۳.۱۰ یا بالاتر](https://www.python.org/downloads/) را نصب کنید
   (هنگام نصب حتماً گزینه **Add Python to PATH** را تیک بزنید).
۲. روی فایل **`start.bat`** دوبار کلیک کنید.

بار اول، پیش‌نیازها به‌صورت خودکار در یک محیط مجازی (`.venv`) نصب می‌شوند و سپس
مرورگر روی نشانی `http://127.0.0.1:5000` باز می‌شود. دفعات بعد فقط برنامه اجرا می‌شود.

برای بستن برنامه، پنجره مشکی (Command Prompt) را ببندید.

### ساخت اپلیکیشن پنجره‌ای ویندوز (PersianPayroll.exe)

برای داشتن یک **اپلیکیشن پنجره‌ای ویندوز** که **بدون نصب پایتون** و با دوبار کلیک
اجرا شود و **مرورگر باز نکند**، روی ویندوز فایل **`build_exe.bat`** را اجرا کنید.
خروجی در پوشه‌ی `dist\PersianPayroll` آماده می‌شود (شامل exe، دیتابیس، بکاپ‌ها،
README و چک‌لیست). برنامه با pywebview داخل یک پنجره native ویندوز نمایش داده
می‌شود (عنوان «حسابداری نیروهای نصب»، ۱۲۰۰×۸۰۰). راهنمای کامل در فایل
**`BUILD_WINDOWS.md`** است.

> توجه: PyInstaller امکان cross-compile ندارد؛ ساخت `.exe` باید روی خود ویندوز انجام شود.

### حالت‌های اجرا

| حالت | فایل | رفتار |
|---|---|---|
| اپلیکیشن ویندوزی (نهایی) | `desktop.py` → `PersianPayroll.exe` | پنجره native، بدون مرورگر |
| مرورگری (توسعه) | `run_web.py` یا `run.bat` یا `start.bat` | باز شدن مرورگر روی `127.0.0.1:5000` |

## اجرا با خط فرمان

(ویندوز، لینوکس یا مک)

```bash
pip install -r requirements.txt
python run.py
```

سپس مرورگر روی `http://127.0.0.1:5000` باز می‌شود. اگر خودکار باز نشد، همین نشانی
را دستی در مرورگر وارد کنید.

## یوزر و پسورد اولیه

در اولین اجرا یک کاربر مدیر ساخته می‌شود:

| | |
|---|---|
| **نام کاربری** | `admin` |
| **رمز عبور** | `admin` |

> ⚠️ پس از اولین ورود، **حتماً رمز عبور را تغییر دهید.**

برای تعیین نام کاربری/رمز دلخواه در همان اولین اجرا (پیش از ساخت دیتابیس)
می‌توانید متغیرهای محیطی زیر را تنظیم کنید:

```bash
set ADMIN_USERNAME=myadmin
set ADMIN_PASSWORD=my-strong-pass
python run.py
```

## تغییر رمز admin

پس از ورود:

۱. از منوی راست وارد **«تنظیمات»** شوید.
۲. در بخش **«مدیریت کاربران پنل»**، روبه‌روی کاربر `admin` در کادر **«رمز جدید»**
   رمز تازه را وارد کنید.
۳. دکمه **«تغییر رمز»** را بزنید.

> رمزها هرگز به‌صورت متن ساده ذخیره نمی‌شوند؛ همیشه به‌صورت **hash امن**
> (الگوریتم Werkzeug/PBKDF2) نگهداری می‌شوند.

از همین بخش می‌توانید کاربر جدید بسازید، کاربر را فعال/غیرفعال کنید یا حذف کنید.

## مسیر ذخیره دیتابیس

تمام اطلاعات (پروژه‌ها، نیروها، درصدها، پرداخت‌ها، تسویه‌ها و کاربران) در یک فایل
SQLite ذخیره می‌شوند:

```
instance/payroll.db
```

این فایل کنار پوشه برنامه قرار دارد. برای انتقال کل برنامه به سیستم دیگر، کافی است
همین فایل (یا کل پوشه پروژه) را کپی کنید.

## بکاپ گرفتن

**بکاپ خودکار:** هر بار که برنامه اجرا می‌شود، **پیش از هر تغییر ساختار دیتابیس**
یک بکاپ خودکار با نام `auto_backup_<تاریخ>_<ساعت>.db` ساخته می‌شود. فقط
۳۰ بکاپ خودکار آخر نگه داشته می‌شود (این عدد در تنظیمات قابل تغییر است؛ بکاپ‌های
دستی هرگز حذف نمی‌شوند). بکاپ خودکار را می‌توان در تنظیمات خاموش کرد.

**بکاپ دستی:**

۱. وارد **«تنظیمات»** شوید.
۲. در بخش **«بکاپ دیتابیس»**، دکمه **«تهیه بکاپ جدید»** را بزنید.

یک کپی کامل و سالم از دیتابیس با نام تاریخ‌دار (مثلاً
`payroll_backup_20260619_142530.db`) در پوشه زیر ساخته می‌شود:

```
backups/
```

از همان صفحه می‌توانید هر بکاپ (خودکار یا دستی) را با دکمه **«دانلود»** روی سیستم
خود ذخیره کنید (مثلاً برای نگهداری روی فلش یا فضای ابری).

> بکاپ با استفاده از API رسمی بکاپ SQLite گرفته می‌شود؛ بنابراین حتی اگر برنامه
> در حال استفاده باشد، فایل بکاپ سالم و یکپارچه خواهد بود.

## به‌روزرسانی امن دیتابیس (Migration)

هنگام نصب نسخه جدید، ساختار دیتابیس به‌صورت **خودکار، امن و افزایشی** به‌روز
می‌شود: ستون‌ها و جدول‌های جدید اضافه می‌شوند بدون آن‌که داده‌های قبلی پاک شوند.
پیش از هر تغییر ساختار، یک بکاپ خودکار گرفته می‌شود و فایل `instance/payroll.db`
هرگز حذف یا بازنویسی نمی‌شود. در صورت نیاز می‌توانید مهاجرت را دستی هم اجرا کنید:

```bash
flask --app run migrate
```

## ریستور (بازگردانی) بکاپ

بازگردانی به‌صورت دستی و بسیار ساده انجام می‌شود:

۱. **برنامه را ببندید** (پنجره Command Prompt را ببندید).
۲. به پوشه `backups/` بروید و فایل بکاپ موردنظر را پیدا کنید
   (مثلاً `payroll_backup_20260619_142530.db`).
۳. آن فایل را در پوشه `instance/` کپی کنید و نام آن را دقیقاً به
   **`payroll.db`** تغییر دهید (فایل قبلی را در صورت نیاز جایگزین کنید).
۴. برنامه را دوباره اجرا کنید.

> 💡 پیشنهاد: پیش از ریستور، یک‌بار از فایل فعلی `instance/payroll.db` هم یک کپی
> با نام دیگر بگیرید تا در صورت اشتباه، قابل بازگشت باشد.

## داده نمونه (Demo)

برای آزمایش سریع می‌توانید داده نمونه بسازید. **این داده هرگز خودکار ساخته
نمی‌شود** و فقط با دستور زیر اضافه می‌شود:

```bash
flask --app run seed-demo
```

یا بدون نصب flask به‌صورت سراسری:

```bash
python -m payroll.demo
```

برای پاک‌سازی داده‌های فعلی و ساخت دوباره نمونه:

```bash
flask --app run seed-demo --reset
```

داده نمونه شامل:

- دو نیرو: «علی رضایی» و «رضا محمدی» با درصد پیش‌فرض ۳۰٪
- یک پروژه «پروژه نمونه نصب» با مبلغ ۱۰٬۰۰۰٬۰۰۰ تومان
- محاسبه: ۳۰٪ + ۳۰٪ نیروها (هرکدام ۳٬۰۰۰٬۰۰۰) و سهم مغازه ۴۰٪ (۴٬۰۰۰٬۰۰۰)

## ساختار پروژه

ساختار ماژولار و قابل توسعه به نسخه وب/سروری:

```
payroll/
  __init__.py        کارخانه اپلیکیشن (app factory) + ثبت Blueprintها و فیلترها
  config.py          پیکربندی (کلید نشست، مسیر دیتابیس و بکاپ)
  db.py              لایه دیتابیس SQLite + داده‌های اولیه
  schema.sql         ساختار جداول
  auth.py            احراز هویت (ورود/خروج، دکوریتورهای دسترسی)
  jalali.py          تاریخ شمسی و ارقام فارسی
  utils.py           قالب‌بندی اعداد و محاسبات مالی
  queries.py         پرس‌وجوهای مشترک (داشبورد، تسویه، گزارش)
  demo.py            ساخت داده نمونه (دستور seed-demo)
  blueprints/        dashboard, workers, projects, payments, settlement,
                     expenses, customer, reports, settings
templates/           قالب‌های فارسی RTL
static/              CSS و JS
run.py               اجرای محلی
start.bat            اجرای ساده روی ویندوز
test_smoke.py        تست دود (محاسبات و مسیرهای اصلی)
TEST_CHECKLIST.md    چک‌لیست تست دستی
```

به دلیل جداسازی لایه دیتابیس و استفاده از Blueprintها، تبدیل این نسخه به یک
سرویس تحت وب/سروری در آینده بدون بازنویسی منطق برنامه ممکن است (مثلاً جایگزینی
SQLite با PostgreSQL و افزودن WSGI server).

## خروجی Excel و PDF

در صفحه **گزارش‌ها**:

- دکمه **«خروجی Excel»** یک فایل `.xlsx` راست‌چین آماده دانلود می‌سازد.
- دکمه **«خروجی PDF / چاپ»** یک صفحه چاپ‌پسند باز می‌کند؛ از همان‌جا با گزینه
  *Print → Save as PDF* مرورگر می‌توانید PDF فارسی تهیه کنید (بدون نیاز به
  کتابخانه اضافی و کاملاً آفلاین).
