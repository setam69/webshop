# پلتفرم حسابداری دستمزد پروژه‌های نصب

یک نرم‌افزار حسابداری **محلی (Local)** و **فارسی/راست‌چین** برای مدیریت دستمزد
پروژه‌های نصب. هر پروژه یک مبلغ دستمزد کل دارد و هر نیروی نصب درصد مشخصی از آن را
می‌گیرد؛ باقی‌مانده سهم مغازه است.

> نسخه اول کاملاً **آفلاین** روی ویندوز/لینوکس اجرا می‌شود، دیتابیس **SQLite**
> دارد و نیازی به سرور، هاست یا اینترنت ندارد.

## امکانات

- **داشبورد:** تعداد پروژه‌ها، مجموع دستمزد، سهم نیروها، سهم مغازه، بدهی به نیروها، پروژه‌های تسویه‌نشده.
- **مدیریت نیروها:** نام، تماس، درصد پیش‌فرض، وضعیت فعال/غیرفعال، توضیحات.
- **ثبت پروژه:** انتخاب نیروها و درصد هر نیرو برای همان پروژه، با **محاسبه زنده** سهم‌ها و سهم مغازه.
- **اعتبارسنجی:** اگر مجموع درصدها بیش از ۱۰۰٪ شود اجازه ثبت داده نمی‌شود.
- **جزئیات پروژه:** سهم هر نیرو، پرداخت‌ها، مانده طلب و تغییر وضعیت.
- **تسویه حساب نیروها:** صورتحساب کامل هر نیرو، ثبت پرداخت و تسویه کامل.
- **گزارش‌ها:** پروژه‌ها، درآمد مغازه، سهم نیروها، بدهی، تسویه‌نشده‌ها — با خروجی **Excel** و **PDF/چاپ**.
- **تنظیمات:** واحد پول، درصد پیش‌فرض مغازه، مدیریت کاربران، **بکاپ دستی** دیتابیس.
- **ورود با نام کاربری و رمز عبور**.

## فرمول محاسبه

```
سهم هر نیرو      = مبلغ کل دستمزد × درصد نیرو ÷ ۱۰۰
مجموع سهم نیروها = جمع سهم همه نیروها
سهم مغازه        = مبلغ کل دستمزد − مجموع سهم نیروها
```

## اجرا روی ویندوز (ساده‌ترین روش)

۱. [Python 3.10+](https://www.python.org/downloads/) را نصب کنید (گزینه *Add to PATH* را بزنید).
۲. روی فایل **`start.bat`** دوبار کلیک کنید.
   بار اول پیش‌نیازها به‌صورت خودکار نصب می‌شوند و سپس مرورگر باز می‌شود.

## اجرا با خط فرمان (ویندوز/لینوکس/مک)

```bash
pip install -r requirements.txt
python run.py
```

سپس مرورگر روی `http://127.0.0.1:5000` باز می‌شود.

### ورود اولیه

- نام کاربری: `admin`
- رمز عبور: `admin`

> پس از اولین ورود، حتماً از بخش **تنظیمات ← مدیریت کاربران** رمز عبور را تغییر دهید.
> برای تعیین رمز دلخواه در اولین اجرا می‌توانید متغیرهای محیطی `ADMIN_USERNAME` و
> `ADMIN_PASSWORD` را تنظیم کنید.

## محل ذخیره اطلاعات

- دیتابیس: `instance/payroll.db`
- بکاپ‌ها: پوشه `backups/`

برای انتقال برنامه به سیستم دیگر، کل پوشه را کپی کنید یا از بخش تنظیمات بکاپ بگیرید.

## ساختار پروژه (ماژولار و قابل توسعه به نسخه وب)

```
payroll/
  __init__.py        کارخانه اپلیکیشن (app factory) + ثبت Blueprintها
  config.py          پیکربندی
  db.py              لایه دیتابیس SQLite
  schema.sql         ساختار جداول
  auth.py            احراز هویت
  jalali.py          تاریخ شمسی
  utils.py           قالب‌بندی و محاسبات مالی
  queries.py         پرس‌وجوهای مشترک
  blueprints/        dashboard, workers, projects, payments, settlement, reports, settings
templates/           قالب‌های فارسی RTL
static/              CSS و JS
run.py               اجرای محلی
start.bat            اجرای ساده روی ویندوز
```

به دلیل جداسازی لایه دیتابیس و استفاده از Blueprintها، تبدیل این نسخه به یک
سرویس تحت وب/سروری در آینده بدون بازنویسی منطق برنامه ممکن است (مثلاً جایگزینی
SQLite با PostgreSQL و افزودن WSGI server).

## خروجی PDF

برای گزارش‌ها دکمه «خروجی PDF / چاپ» یک صفحه چاپ‌پسند باز می‌کند؛ از همان‌جا با
گزینه *Print → Save as PDF* مرورگر می‌توانید فایل PDF فارسی تهیه کنید (بدون نیاز
به کتابخانه اضافی، کاملاً آفلاین).
